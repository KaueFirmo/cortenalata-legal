Política de privacidade

Corte na Lata Uploader · atualizada em 19 de novembro de 2026

O Corte na Lata Uploader é a ferramenta interna do canal Corte na Lata. Esta política explica quais dados ela acessa, por quê, onde ficam e como apagar.

Quem usa

Só o dono do canal Corte na Lata. A ferramenta não tem cadastro, não é oferecida a outras pessoas e não coleta dados de quem assiste aos vídeos.

Dados acessados pela API do YouTube

Com a autorização do dono do canal (login do Google), a ferramenta usa os Serviços de API do YouTube para:

  • Enviar vídeos ao canal Corte na Lata (permissão youtube.upload);
  • Ler informações do próprio canal: nome, número de inscritos, lista dos vídeos enviados e as estatísticas públicas de cada um, como views, curtidas e comentários (permissão youtube.readonly).

A ferramenta não lê mensagens, histórico, inscrições, dados de pagamento nem informações de outros canais ou usuários.

Para que esses dados servem

  • Publicar os cortes editados no horário programado;
  • Mostrar ao dono do canal, num painel que roda só no computador dele, como cada vídeo está indo.

Onde ficam e com quem são compartilhados

  • A autorização (token do Google) e as estatísticas ficam guardadas somente no computador do dono do canal. Não há servidor nosso, banco de dados na nuvem nem cópia em outro lugar.
  • Os dados não são vendidos, compartilhados nem usados para anúncios, e não são passados a terceiros.
  • Não usamos cookies nem rastreadores neste site.

Por quanto tempo

As estatísticas ficam guardadas enquanto o painel for usado. Os vídeos baixados para edição são apagados depois de publicados, e os descartados em até 3 dias.

Como revogar o acesso e apagar os dados

  • Revogue a permissão a qualquer momento em myaccount.google.com › Segurança › Apps de terceiros. Sem ela, a ferramenta para de acessar o canal na hora.
  • Para apagar os dados guardados, basta excluir a pasta da ferramenta no computador, com o token e o banco de dados locais. Pedidos também podem ser feitos pelo canal; respondemos em até 7 dias.

Serviços do Google

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Mudanças e contato

Se esta política mudar, a data no topo é atualizada. Contato pelo canal: youtube.com/@CortesnasLata.

Privacy policy (English)

Last updated November 19, 2026

Corte na Lata Uploader is an internal tool used only by the owner of the Corte na Lata YouTube channel. It has no sign-up, is not offered to the public and collects no data from viewers.

Data accessed. With the channel owner's Google authorization, it uses YouTube API Services to (1) upload videos to the Corte na Lata channel (youtube.upload) and (2) read that channel's own information: title, subscriber count, list of uploaded videos and their public statistics such as views, likes and comments (youtube.readonly). It does not access messages, history, subscriptions, payment data or any other channel or user.

Use. Publishing the edited clips on schedule and showing the owner, in a dashboard that runs only on the owner's computer, how each video performs.

Storage and sharing. The Google token and statistics are stored only on the channel owner's computer. There is no server or cloud database of ours. Data is never sold, shared, used for advertising or transferred to third parties. This website uses no cookies or trackers.

Retention and deletion. Statistics are kept while the dashboard is in use; downloaded videos are deleted after publishing (discarded ones within 3 days). Revoke access anytime at Google Account › Security › Third-party apps, and delete the tool's local folder to erase all stored data. Requests can be made through the channel and are answered within 7 days.

Google. This tool uses YouTube API Services: YouTube Terms of Service, Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: youtube.com/@CortesnasLata.
